The Orbit Philosophy

관계는 평가가 아니라 움직임으로 보입니다

사람을 숫자로 평가하지 않고, 나와의 실제 교류와 거리로 표현하는 인간 중심 철학.

🌌

Canvas Physics & Semantic Zoom

다체 충돌 이완(Collision relaxation)과 중력 가속도 기반으로 인물 노드들이 서로 겹치지 않고 안정된 궤도를 유지합니다.

🔐

Per-User AES-256-GCM Envelope Encryption

모든 관계 메모와 기억은 사용자별 고유 데이터 키로 암호화되며, 단일 트랜잭션 기반 무중단 키 회전(Key Rotation)을 완벽히 지원합니다.

🤖

AI Relationship Co-Pilot

과거 기억 맥락을 참조하여 소원해진 인연과의 따뜻한 교류 전략과 다음 미팅 아젠다를 제안하는 SSE 스트리밍 Co-Pilot.

🔌

Streamable HTTP MCP (/mcp)

Dual-Era 사양을 충족하는 표준 Model Context Protocol 서버로 외장 AI 에이전트와 관계 컨텍스트를 안전하게 상호운용합니다.

🛡️

Enterprise Approvals & Governance

외부 이해관계자나 주요 기억 등록 시 팀장의 검토와 승인을 거치는 엔터프라이즈 거버넌스 워크플로우를 제공합니다.

📦

Offline Air-Gapped Monolith

Go 단일 바이너리 내에 React 19 SPA를 완벽히 임베딩하여 인터넷이 없는 폐쇄망 환경에서도 100% 자립 구동됩니다.

Frequently Asked Questions

자주 묻는 질문 (FAQ)

Orbit의 기능, 보안 아키텍처 및 MCP 연동에 대한 핵심 안내입니다.

Orbit은 기존 CRM이나 주소록과 무엇이 다른가요?
일반적인 CRM은 인간관계를 비즈니스 파이프라인이나 점수로 환원합니다. 반면 Orbit은 나를 중심 항성(Core Sun)으로 두고, 상대방과의 중요도와 교류 빈도에 따라 공전 궤도(Orbit)와 거리를 시각화합니다. 나와 상대방 사이의 살아 숨쉬는 상호작용과 기억을 우주적 관점으로 다루는 프라이빗 관계 플랫폼입니다.
개인정보와 소중한 기억은 어떻게 암호화되어 보호되나요?
Orbit은 2계층 봉투 암호화(Two-Tier AES-256-GCM Envelope Encryption)를 사용합니다. 각 사용자마다 고유한 데이터 암호화 키(DEK)가 발급되며, 연락처 메모, 상호작용 기록, 기억 내용이 완전히 분리되어 암호화됩니다. 또한 개인화 메뉴에서 서비스 중단 없이 실시간으로 키를 재암호화하는 무중단 키 회전(Zero-Downtime Key Rotation)을 지원합니다.
Streamable HTTP MCP(/mcp)는 무엇이며 어떻게 연동하나요?
Orbit은 AI 에이전트 도구 연동 표준인 Model Context Protocol(MCP)을 기본 지원합니다. 최신 2026-07-28 규격과 레거시 초기화 규격을 모두 지원하는 Dual-Era 서버이며, /mcp 엔드포인트를 통해 외부 AI가 인물 검색(orbit_search_people), 관계 상세 조회(orbit_get_relationship), 기억 보관(orbit_create_memory) 도구를 안전한 스코프 권한 하에 호출할 수 있습니다.
인터넷 연결이 없는 오프라인 폐쇄망(Air-Gapped)에서도 구동 가능한가요?
네, 100% 완전 독립 구동이 가능합니다. Orbit은 단일 Go 실행 파일 내에 React 19 웹 프론트엔드 에셋을 완전히 임베딩(go:embed)하고 있으므로, 외부에 일체의 CDN이나 정적 파일 요청을 보내지 않습니다. 오프라인 망에서 PostgreSQL 16+ 컨테이너와 4개의 필수 환경변수만 설정하면 즉시 완벽하게 동작합니다.
조직 모드에서 승인(Approvals) 거버넌스는 어떻게 동작하나요?
관리자가 승인 워크플로우를 활성화한 경우, 팀원이 외부 주요 이해관계자를 등록하거나 민감한 기억을 저장하면 즉시 [검토 및 승인] 대기열로 이동합니다. 팀장은 변경 사유와 분류를 확인한 후 승인 또는 피드백과 함께 반려할 수 있으며, 승인된 항목만 정식 궤도에 안전하게 진입합니다.

Ready to launch?

30초 만에 로컬에서 실행하기

단 4개의 환경변수로 나만의 관계 우주를 즉시 기동하세요.

bash · quickstart.sh
# 1. PostgreSQL 컨테이너 실행
docker run -d --name orbit-db -p 5432:5432 -e POSTGRES_USER=orbit -e POSTGRES_PASSWORD=orbit -e POSTGRES_DB=orbit postgres:16-alpine

# 2. 필수 환경변수 설정 (정확히 4개)
export DATABASE_URL='postgresql://orbit:orbit@127.0.0.1:5432/orbit?sslmode=disable'
export BOOTSTRAP_ADMIN='admin@example.internal'
export BOOTSTRAP_ADMIN_PASSWORD='a-long-bootstrap-password'
export ENCRYPTION_KEY="$(openssl rand -base64 32)"

# 3. Orbit 서비스 빌드 및 실행
./orbit

# 4. 브라우저에서 http://localhost:8080 접속!
