The Orbit Philosophy

관계는 평가가 아니라 움직임으로 보입니다

🌌

Canvas Physics & Semantic Zoom

충돌 이완(Collision relaxation)과 중력 가속도 기반으로 인물들이 서로 겹치지 않고 안정된 위치를 유지합니다.

🔐

Per-User Envelope Encryption

모든 교류 기록과 소중한 기억은 사용자별 AES-256-GCM 데이터 키로 완벽하게 암호화되어 보존됩니다.

🤖

AI Co-Pilot & Rediscover

오랜 시간 소원해진 인연을 다시 환기하고, 과거 나눈 이야기 맥락을 기반으로 따뜻한 대화 전략을 제안합니다.

🔌

Streamable HTTP MCP

/mcp 엔드포인트를 통해 AI 에이전트 도구와 안전하게 나의 관계 맥락을 실시간 공유할 수 있습니다.

Ready to launch?

30초 만에 로컬에서 실행하기

bash · quickstart.sh
# 1. PostgreSQL 컨테이너 실행
docker run -d --name orbit-db -p 5432:5432 -e POSTGRES_USER=orbit -e POSTGRES_PASSWORD=orbit -e POSTGRES_DB=orbit postgres:16-alpine

# 2. 필수 환경변수 설정 (정확히 4개)
export DATABASE_URL='postgresql://orbit:orbit@127.0.0.1:5432/orbit?sslmode=disable'
export BOOTSTRAP_ADMIN='admin@example.internal'
export BOOTSTRAP_ADMIN_PASSWORD='a-long-bootstrap-password'
export ENCRYPTION_KEY="$(openssl rand -base64 32)"

# 3. Orbit 서비스 빌드 및 실행
./orbit

# 4. 브라우저에서 http://localhost:8080 접속!
