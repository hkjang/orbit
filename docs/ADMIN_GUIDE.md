# 관리자 가이드

서비스 관리 콘솔(`/admin`)에서 다루는 설정 가운데 동작을 알고 써야 하는 것을
적는다. 화면 구성은 [사용자 가이드 §2.9](guide.md#29-서비스-관리-콘솔-admin),
배포와 환경 변수는 [오프라인 배포](OFFLINE.md)를 본다.

## 방문 추적

**방문 추적** 탭에서 어떤 화면이 실제로 쓰이는지 재는 스크립트를 붙인다.
설정은 저장소(`settings` 테이블의 `system:tracking`)에 있고 화면에서 바꾸며, 다시
배포하지 않아도 저장 즉시 다음 페이지 로드부터 적용된다.

**기본값은 꺼짐이다.** 새로 설치했거나 이 탭을 손대지 않은 곳에서는 페이지도
정책도 아무것도 달라지지 않는다.

| 설정 | 기본값 | 뜻 |
| --- | --- | --- |
| 방문 추적 사용 (`enabled`) | **꺼짐** | 관리자가 켜야 스니펫이 붙는다 |
| 추적 도구 (`provider`) | 없음 | `momento` · `ga4` · `gtm` · `matomo` · `custom` |
| Momento 수집기 주소 · 사이트 ID (`momento_url` · `momento_site_id`) | 비어 있음 | Momento 콘솔의 **사이트 → SDK 설치** 에 있는 값 |
| 같은 오리진 프록시 (`momento_proxy`) | 켜짐 | 아래 참고. 가능하면 이 경로를 쓴다 |
| 측정 ID (`measurement_id`) | 비어 있음 | GA4 의 `G-…`, GTM 의 `GTM-…` |
| Matomo 주소 · 사이트 ID (`matomo_url` · `matomo_site_id`) | 비어 있음 | |
| 추적 코드 (`custom_snippet`) | 비어 있음 | 붙여 넣은 스니펫. **8KB** 를 넘으면 저장되지 않는다 |
| 추가 허용 출처 (`allowed_hosts`) | 비어 있음 | 스니펫에서 자동으로 읽지 못한 출처를 쉼표로 더한다 |
| 관리 화면도 추적 (`include_admin`) | 꺼짐 | 켜지 않으면 `/admin` 에는 붙지 않는다 |
| 넣는 자리 (`placement`) | `head` | `head` 또는 `body` 의 끝 |

### Momento 를 먼저 고른다

Momento 는 사내 자체 호스팅 수집기라 방문 데이터가 밖으로 나가지 않는 유일한
선택지다. 그래서 목록의 첫 자리에 있다.

**같은 오리진 프록시(기본).** 켜 두면 Orbit 이 `/momento/*` 를 수집기로 넘긴다.
브라우저는 `/momento/tracker.js` 에서 로더를 받고 `/momento/collect/…` 로 이벤트를
보내므로, 정책에 외부 출처가 아예 등장하지 않는다 — 수집기 주소를 브라우저가
직접 부를 수 없는 망 구성에서도 동작한다. 프록시는 추적기 로더와 수집 끝점만
넘기고 Momento 콘솔은 열지 않으며, Orbit 세션 쿠키는 수집기로 보내지 않는다.
추적이 꺼져 있거나 프록시를 끄면 `/momento/*` 는 없는 경로(404)다.

```html
<script async src="/momento/tracker.js"
        data-site-id="SITE_…" data-environment="prd"
        data-contract-version="1" data-endpoint="/momento"></script>
```

**직접 연결.** 프록시를 끄면 스니펫이 수집기 주소를 직접 부르고, 그 출처가
`script-src` · `connect-src` · `img-src` 에 더해진다. Momento 의 허용 도메인에
Orbit 의 공개 URL 이 등록돼 있어야 한다.

### CSP — 왜 스니펫을 그냥 붙이면 안 되는가

Orbit 의 모든 화면은 `script-src 'self'` 로 잠겨 있다. 앱 자신의 번들만 실행되고,
인라인 스크립트도 외부 스크립트도 브라우저가 **조용히** 막는다. 스니펫을 HTML 에
그냥 넣으면 화면은 멀쩡한데 수집이 들어오지 않고, 이유는 브라우저 콘솔에만
남는다.

그래서 Orbit 은 정책을 `'unsafe-inline'` 으로 풀지 않는다. 한 번 풀면 그 앱의
모든 인라인 스크립트가 함께 허용되고, 추적을 끈 뒤에도 정책은 느슨한 채로 남기
때문이다. 대신 다음 세 가지를 한다.

1. **요청마다 nonce.** 페이지 셸을 내보낼 때마다 새 nonce 를 만들어 스니펫의
   **모든** `<script>` 태그에 붙이고, 같은 값을 `script-src 'nonce-…'` 에 넣는다.
   붙여 넣은 스니펫은 고칠 필요가 없다 — Orbit 이 태그를 찾아 단다. 대소문자가
   섞인 `<SCRIPT>` 도, `İ` 같은 글자가 앞에 있어도 제자리에 붙는다.
2. **출처는 스니펫에서 읽는다.** 추적 도구는 로더 안에 자기 주소를 적어 둔다.
   Orbit 은 스니펫의 `http(s)` 출처를 긁어 `script-src` · `connect-src` · `img-src`
   에 더한다. 저장 전에 화면이 "정책에 더해지는 출처" 를 미리 보여 준다.
   자동으로 못 읽은 것은 **추가 허용 출처** 에 손으로 더한다.
3. **막힌 것을 기록해 보여 준다.** 추적이 켜진 동안에만 정책에 `report-uri` 를
   넣어 브라우저가 거절한 요청을 `/api/v1/tracking/csp-report` 로 신고하게 한다.
   탭 아래 **정책이 막은 출처** 에 출처와 지시어가 보이고, **허용에 더하기** 를
   누르면 그 출처가 허용 목록에 들어간다. 기록은 메모리에만 두며 서로 다른 출처
   100개까지 남긴다 — 횟수가 아니라 어떤 출처가 막혔는지가 중요하기 때문이다.
   **비우기** 로 지우고 다시 띄워 보면 아직 막히는 것이 있는지 알 수 있다.

추적을 끄면 정책은 원래대로 돌아간다. nonce 도 `report-uri` 도 더한 출처도 남지
않는다.

**붙지 않는 곳.** `/api/*` · `/mcp` · `/healthz` · `/readyz` · `/openapi.json` ·
`/momento/*` 같은 화면이 아닌 경로에는 스니펫이 붙지 않고, 정책도
`default-src 'none'` 으로 더 좁다. `/admin` 은 **관리 화면도 추적** 을 켰을 때만
붙는다. 로그인 화면에는 붙지만 Orbit 이 개인 식별 값을 스니펫에 넘기지는
않는다.

**켜기 전에 확인할 것.**

- 저장 버튼이 비활성이면 그 위의 경고가 빠진 값을 말한다. 꺼진 채로는 값을
  미리 적어 둘 수 있다.
- 켠 뒤 화면을 한 번 띄우고 수집기에서 수신을 확인한다. 들어오지 않으면
  **정책이 막은 출처** 를 본다 — 비어 있으면 정책 문제가 아니라 스니펫이나
  수집기 쪽이다.
- Momento 프록시를 쓰면 정책에 외부 출처가 없어야 정상이다. "정책에 더해지는
  외부 출처가 없습니다" 가 맞는 상태다.
